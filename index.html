Evidence, assumptions & limitations

  • Source-observed fields, calculated sample metrics, proposed designs and unknown implementation details are kept separate.
  • The user snapshot does not contain the timestamped event and transaction history needed to calculate actual DAU trends, retention, reward conversion or withdrawal success.
  • Proposed events, data models, controls and architecture are specifications, not claims about existing production implementation.
  • The original user-level source workbook is intentionally excluded from this public repository because it contains name/email-style columns.
