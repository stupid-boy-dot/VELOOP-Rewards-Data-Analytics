Data integrity and limitations

Important: All supplied Task 01 records are explicitly simulated/fictional. Calculations describe only the exercise sample. Proposed events, pipelines and dashboards are not verified production implementations.
  • The clean sample is 1,000 rows; the messy 1,008-row sheet is a QA fixture and is excluded from KPI denominators.
  • Supplied 7-day and 30-day flags are not event-derived DAU/MAU or retention.
  • Referral acquisition is not referral conversion; withdrawal request is not successful payout.
  • The original row-level workbook and raw profile snapshot are excluded from public hosting; public-safe aggregate outputs are provided.
  • This website is a static project showcase and review index, not an interactive BI dashboard or VELOOP production application.
