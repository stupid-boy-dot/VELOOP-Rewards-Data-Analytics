# VELOOP Rewards — Data Analytics

**Internship:** VELOOP Rewards Data Analyst Internship  
**Assignment:** Task 01 — Product Analytics, Data Readiness & Data Management Blueprint  
**Project status:** Pre-submission review / documentation in progress

## Project objective

Build a reliable, traceable and reusable analytical foundation for a developing rewards and engagement product. The work identifies what VELOOP should collect, how the information should be structured, how data quality should be controlled, what management should measure, and what engineering would need to implement.

This is an analytics-design assignment. A dashboard blueprint is a specification; it is not evidence that a production dashboard or tracking system has been deployed.

## Work areas

- Product data readiness audit and data coverage matrix
- User and account lifecycle analytics
- Earning, task and reward analytics
- Wallet and withdrawal analytics
- Referral and engagement analytics
- Production event tracking plan and developer handoff
- Data dictionary and logical data model
- KPI catalogue and dashboard blueprint
- Simulated data profiling and data-quality audit
- Data pipeline, privacy, access, governance and change-management proposals
- Analytics gap assessment, assumptions register and prioritised implementation backlog

## Data integrity

The assignment explicitly states that supplied Task 01 data is fictional/simulated and must never be presented as actual VELOOP production performance. The project separates:
- **Source-observed:** fields and records present in the supplied assignment workbook
- **Calculated:** metrics reproducibly derived from that simulated source
- **Proposed:** recommended events, fields, controls, data models and architecture
- **To Be Verified:** implementation or product details not evidenced by the supplied material

No production statistics, internal implementation status, failure codes, security mechanisms or company targets are invented.
