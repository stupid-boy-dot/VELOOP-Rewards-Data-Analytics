# Data Folder — Publication Rules

This folder is reserved for approved, review-safe analytical datasets and data documentation.

The original Task 01 workbook is intentionally not committed to this public repository because its user sheet includes name and email-style columns. Although the assignment labels the dataset as simulated, it is better practice not to publish user-level contact-style fields unnecessarily.

Any dataset published here must:
- Be clearly labelled SIMULATED / FICTIONAL where applicable.
- Include its generation or source methodology.
- Avoid real personal data, credentials, secrets and private information.
- Keep source-observed facts separate from generated fixtures.
- Never be represented as actual VELOOP production performance.
